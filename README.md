# Teaching Assignment System

Hệ thống hỗ trợ quyết định phân công giảng dạy giáo viên dựa trên chuyên môn, định mức và tối ưu hóa ràng buộc đa mục tiêu.

## Trạng thái

Dự án đang ở giai đoạn chuẩn bị và phân tích. Nền kỹ thuật Spring Boot, React, PostgreSQL và Timefold sẽ được khởi tạo ở bước tiếp theo sau khi nhóm chốt các quyết định nghiệp vụ.

## Cấu trúc repository

```text
backend/          Mã nguồn backend (sẽ dùng Java Spring Boot)
frontend/         Mã nguồn giao diện
infra/            Cấu hình hạ tầng và triển khai
docs/             Tài liệu dự án
.github/          Workflow và template GitHub trong tương lai
```
